# PPG Portfolio CMS — Digital Teaching Portfolio

CMS Portfolio PPG merupakan sistem pengelolaan konten yang dirancang untuk memudahkan pengelolaan dan pembaruan informasi pada website portofolio PPG. Melalui CMS ini, pengguna dapat mengatur berbagai konten seperti profil, pengalaman praktik, perangkat pembelajaran, dokumentasi kegiatan, proyek, refleksi, serta karya yang telah dihasilkan selama mengikuti Program Pendidikan Profesi Guru.

CMS dibuat dengan antarmuka yang sederhana dan terstruktur sehingga proses menambah, mengedit, menghapus, dan mengelola konten dapat dilakukan secara efisien tanpa perlu melakukan perubahan langsung pada kode website. Dengan demikian, seluruh perjalanan dan hasil pengembangan kompetensi selama PPG dapat terdokumentasi secara rapi, dinamis, dan mudah diakses.

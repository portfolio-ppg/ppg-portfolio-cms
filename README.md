# ppg-portfolio-cms
CMS untuk mengelola portofolio digital PPG secara terstruktur dan dinamis. Menyediakan pengelolaan profil, pengalaman praktik, perangkat pembelajaran, proyek, dokumentasi kegiatan, refleksi, serta karya selama mengikuti Program Pendidikan Profesi Guru dalam satu platform yang modern dan mudah digunakan.
